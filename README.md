# LF Cine — downloads

Este repositório contém somente os instaladores e os arquivos necessários para
atualizar o LF Cine. O código-fonte não é publicado aqui.

Baixe a versão mais recente na seção **Releases**.

A partir da versão 2.0.4, o app Windows possui um botão de atualização em
Configurações e na tela de login. Versões anteriores precisam de uma instalação
manual para receber esse recurso. Android continua sendo atualizado pelo APK.

Os instaladores ainda não possuem assinatura digital.
